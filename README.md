# 🩺 CureWise
### AI-Powered Healthcare & Disease Prediction System

CureWise is an AI-powered healthcare web application designed to assist users in identifying potential diseases based on symptoms. The platform leverages Machine Learning to provide disease predictions, suggest precautions, and improve awareness while offering an intuitive and responsive user experience.

---

## 📌 Features

- 🤖 AI-based disease prediction
- 🩺 Symptom-based diagnosis
- 📊 Machine Learning prediction model
- 🔒 Secure user authentication
- 📱 Responsive and user-friendly interface
- 📋 Disease information and precautions
- ⚡ Fast prediction results
- 💻 Clean and modern web design

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/CureWise.git
```

### Navigate to the project folder

```bash
cd CureWise
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

The application will start on:

```
http://127.0.0.1:5000/
```
